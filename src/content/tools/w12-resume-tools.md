## What it is

**Google Docs** and **Canva** are free tools for creating resumes. Google Docs is plain and ATS-friendly by default. Canva offers designed templates, but many are multi-column and graphic-heavy, which can hurt ATS parsing, so choose carefully.

## Why PMs use it

You need two polished, one-page resumes (PM and AI PM) that read well to both machines (applicant tracking systems) and humans, are easy to edit for tailoring, and export to clean PDFs.

## Account setup (free plan)

- **Google Docs:** docs.google.com with your Google account.
- **Canva:** canva.com → sign up free. The free plan includes many resume templates.

## Walkthrough: Google Docs (recommended)

### 1. Set up the page
1. Create a new doc: “Resume – PM – base”.
2. **File → Page setup:** A4, margins 1.5–2 cm.
3. Font: a clean sans-serif (e.g., Arial, Roboto, Lato) at 10–11 pt for body, 14–16 pt for your name.

### 2. Build the structure
1. Header: name (bold, larger), then one line: Bengaluru · phone · email · LinkedIn · portfolio (as clickable links: select text → Insert link).
2. Use **bold section headings** in capitals or small caps: SUMMARY, PRODUCT PROJECTS, EXPERIENCE, EDUCATION, SKILLS. (Avoid using real tables for layout.)
3. For each entry: a bold line with project/role name, and on the same line dates aligned right using a **right tab stop** (Format → Align & indent → Indentation options isn’t needed; use the ruler: click to add a right-aligned tab stop near the right margin, then press Tab between name and date).
4. Bullets: use **Format → Bullets & numbering**, simple round bullets; 2–3 per entry.

### 3. Fit to one page
1. Trim weak bullets first.
2. Reduce spacing: Format → Line & paragraph spacing → single; remove extra blank lines.
3. Margins down to 1.5 cm if needed; don’t go below 10 pt font.

### 4. Create the variants
1. **File → Make a copy** → “Resume – AI PM”. Reorder projects (P4 first), adjust summary and skills.
2. For each application, make a copy named “Resume – Company – Role” and tailor (Tailoring lesson).

### 5. Export and check
1. **File → Download → PDF document**.
2. Open the PDF, select all text (Ctrl/Cmd + A), copy, and paste into a plain text editor. Check order and that nothing is missing (ATS check).
3. File name: `Krupa_Surname_PM_Resume.pdf`.

## Walkthrough: Canva (if you prefer)

1. Search “simple resume” and pick a **single-column**, mostly-text template with no photos, icons for contact details are fine but keep text as real text.
2. Replace content; delete skill bars, rating dots and decorative columns.
3. Download as **PDF Standard**; run the same copy-paste ATS check. If text comes out jumbled, switch to Google Docs.

## Tips

- **Content over design**: recruiters remember results, not colours.
- **Consistent formatting**: same date format (“Jan 2023 – Apr 2024”), same bullet style.
- **Hyperlinks** for portfolio and LinkedIn; make sure they work in the PDF.
- **Version control**: keep a dated base version; never edit the base when tailoring.
- **Store your resumes** in the Portfolio page in PM Path (links) and in Google Drive.
